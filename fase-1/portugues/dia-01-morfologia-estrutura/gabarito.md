## Exercício 1

**Resposta (análise possível / didática):**

| Palavra | Elementos |
|---------|-----------|
| *casinhas* | radical `cas-` + vogal temática `i` (em análises escolares: tema *casi-*) + sufixo diminutivo `-nh-` + desinência de número `-as` *(aceite também: `casinh-` + `-as`)* |
| *relógio* | radical `relóg-` (ou `relog-`) + vogal temática/desinência nominal; **sem** prefixo óbvio |
| *cafeteira* | radical `cafe-` + consoante de ligação `t` + sufixo `-eira` |
| *infelizmente* | prefixo `in-` + radical `feliz` + sufixo adverbial `-mente` |

**Desenvolvimento:** comece pelo sentido compartilhado com a família (*casa* → *casinha*; *café* → *cafeteira*; *feliz* → *infeliz* → *infelizmente*). O que sobra costuma ser afixo, desinência ou elemento de ligação.

**Cuidado:** nem toda análise morfológica é “única” no detalhe (ex.: onde corta o diminutivo). O importante é **não confundir radical com afixo** e **não inventar prefixo** onde não há (*re-* de *relógio* não é o prefixo “de novo”).

**Salto de raciocínio:** se a palavra muda de classe ou de sentido claro com um pedaço no início/fim, esse pedaço tende a ser afixo; se só marca plural/gênero/pessoa, tende a ser desinência.

## Exercício 2

**Resposta (exemplos válidos):**

1. Radical `pedr-` — *pedreira*, *pedregulho*, *apedrejar*, *pedreiro*…  
2. Radical `noit-` — *noiteada*, *anoitecer*, *noitinha*, *pernoite*…  
3. Radical `verd-` — *esverdeado*, *verdejante*, *verdura*, *inverdade* (cuidado: *verdade* tem história própria; prefira *verdejo*, *esverdeado*).

**Desenvolvimento:** forme o diminutivo/aumentativo ou um verbo/adjetivo da mesma família; o trecho que se repete é o radical.

**Pegadinha:** palavras parecidas na escrita **não** são automaticamente cognatas (*verde* ≠ *verdade* no uso escolar usual como “mesmo radical de cor”).

## Exercício 3

**Resposta:**

1. *girassol* — composição por **justaposição**  
2. *planalto* — composição por **aglutinação** (*plano* + *alto*, com fusão fonética)  
3. *dentista* — derivação **sufixal** (`dent-` + `-ista`)  
4. *desleal* — derivação **prefixal** (`des-` + *leal*)  
5. *anoitecer* — derivação **parassintética** (`a-` + *noite* + `-ecer`; os dois afixos entram juntos)

**Desenvolvimento:**  
- Um radical + afixo(s) → derivação.  
- Dois radicais → composição.  
- Na parassíntese, tirar só o prefixo ou só o sufixo costuma “quebrar” a formação (*noitecer* / *anoite* não funcionam como etapas naturais).

**Cuidado:** *antissocial* (não pedida aqui) é prefixal (`anti-` + *social*), **não** parassintética — erro clássico de prova.

## Exercício 4

**Resposta:**

a) **Neologismo** é uma palavra (ou sentido) **nova** que entra no uso da língua. *Selfie* veio do inglês e se estabilizou no português; *viralizar* usa mecanismo produtivo da língua (`viral` + `-izar`) para nomear um comportamento recente das redes — ambos ilustram vocabulário em expansão.  
b) O sufixo `-izar` forma **verbo** a partir de base nominal/adjetival e indica, grosso modo, “tornar / fazer com que se torne” (aqui: fazer algo se espalhar como “vírus” de informação).

**Dica:** na prova do ITA, neologismo aparece ligado a **texto**: reconheça o fenômeno e o efeito de sentido, sem precisar de etimologia erudita.

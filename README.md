# Estudos ITA

Material complementar de preparação para o vestibular do **Instituto Tecnológico da Aeronáutica (ITA)**.

Não substitui a escola. O roteiro é **desacoplado** do calendário escolar: avance pelo próximo item em aberto da fase atual.

## Como estudar (sempre a mesma dinâmica)

1. Abra a **fase atual** (comece pela [Fase 1](FASE_1.md)).
2. Faça o **próximo item em aberto** (`[ ]`) da checklist.
3. No arquivo do dia: leia a **Meta**, use os **Links** (vídeoaula) e a **Teoria** na tela.
4. Imprima a seção **Exercícios** (ou a página do dia) e resolva no **papel**.
5. Confira o **Gabarito**.
6. Marque o item como concluído (`[x]`) na página da fase.

Centro do método: **papel e lápis**. A tela serve para ler e imprimir — não para substituir a resolução escrita.

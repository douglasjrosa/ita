# Estudos ITA

Material complementar de preparação para o vestibular do **Instituto Tecnológico da Aeronáutica (ITA)**.

Não substitui a escola. O roteiro é **desacoplado** do calendário escolar: avance pelo próximo item em aberto da fase atual.

## Como estudar (sempre a mesma dinâmica)

1. Abra a **fase atual** (comece pela [Fase 1](FASE_1.md)).
2. Faça o **próximo item em aberto** (`[ ]`) — o link abre a **teoria** do dia.
3. Na teoria: leia a **Meta**, a **Definição** e os **Exemplos**; depois use **Nesta lição** / **Mídias**.
4. Abra **Exercícios**, **imprima** essa página (A4) e resolva no **papel**.
5. Só depois abra o **Gabarito** (resolução comentada).
6. Marque o item como concluído na página da fase (no GitHub, se for registrar progresso no repo).

Centro do método: **papel e lápis**. A tela serve para ler e imprimir.
